# 🌤️ Weather App

A responsive weather application built with **React.js** that shows real-time weather data for any city in the world.

## 🚀 Live Demo
[Click here to view](YOUR_DEPLOYED_LINK)

## 📸 Features
- 🔍 Search weather by city name
- 🌡️ Shows temperature, feels like, humidity, wind speed & pressure
- 🌍 Works for any city worldwide
- 📱 Fully responsive design
- ⚡ Real-time data from OpenWeatherMap API

## 🛠️ Tech Stack
- React.js
- useState, useEffect Hooks
- OpenWeatherMap API
- CSS3 (Glassmorphism UI)

## ⚙️ How to Run Locally

```bash
git clone git remote add origin https://github.com/Naveenkumar-d7/weather-app.git
cd weather-app
npm install
npm start
```

## 📡 API Used
- [OpenWeatherMap API](https://openweathermap.org/api) — Free tier
